# Desktop Window — el sujeto vive en una ventana de OS

**Cuándo usarlo:** contenido tech, producto/software, IA, "mirá esta herramienta";
natural para el contenido Morfeo de apps y AI tools.
**Fuente:** disección preview Shorts Maker "Yellow Frame/Desktop" (Higgsfield) 2026-07 ·
**Validado:** no — **falló en el primer intento (demo omni-edit v1)**: ventanear el frame
crudo arrastra el fondo fuente adentro de la ventana (inaceptable si la fuente tiene
fondo propio, ej. avatar HeyGen con habitación), y el wallpaper "muted gray-blue" del
bloque original salió gris y apagado. Antes de reintentar este estilo: (a) el contenido
de la ventana es EL SUJETO RECORTADO sobre un sólido limpio, nunca el frame crudo;
(b) wallpaper con color con punch y ventanas de alto contraste; (c) labels/captions
GRANDES (≥8% del alto). El bloque de abajo ya incorpora estas correcciones parcialmente,
pero el estilo necesita re-validación con una prueba nueva.

## Bloque de estilo (va literal en el prompt, en inglés)

Keep my talking face, lip-sync and real footage exactly as they are, but place my video
inside a draggable desktop window (rounded corners, subtle window chrome) living on a
clean computer desktop environment: muted gray-blue wallpaper, a dock with app icons at
the bottom, occasional cursor arrows and hand-pointer icons, and browser/app windows
that slide in behind or beside my window as inserts. A bright yellow selection marquee
occasionally frames my window like a drag-select. Flat UI aesthetic, crisp edges, subtle
drop shadows — it must read like a real operating system screen recording, not a mockup.

## Estados de fondo

Los "estados" son eventos de UI por beat de frase: mi ventana se mueve/reencuadra, entra
una ventana de browser con contenido literal a la frase, aparece el marquee amarillo, un
ícono del dock salta. El wallpaper queda constante dentro del clip; puede cambiar de tono
entre clips de la serie.

## Captions

Por frase, como **labels de UI / barras de título** en tipografía de sistema, blanco
sobre pill oscura, con la keyword de la frase resaltada en amarillo. Posición: tercio
bajo, como una notificación. Deletrear siempre, keyword incluida: "UI label spelling
exactly: '… <keyword in yellow> …'".

## Doodads

Ventanas/íconos literales: se nombra una app/objeto → entra una ventana o ícono pixel/flat
de eso (estilo old-computer icon). Un evento de UI por frase, no más.

## QA específico

- Que la UI se lea como sistema real (chrome, sombras, dock) y no como dibujo.
- Texto de labels e íconos del dock: verificar que no invente texto basura ilegible.
- La ventana del sujeto nunca tapa su propia cara con chrome/cursores.
