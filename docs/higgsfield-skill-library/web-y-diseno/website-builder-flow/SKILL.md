# Website Builder

Read this before building or editing a website with the website\_builder tools
(create\_website / deploy\_website / website\_repo\_access). It is the website
template's AGENTS.md — an IMAGE-GROUNDED, phased build pipeline (intake →
concept → reference boards → Higgsfield asset system → build-to-boards →
motion → mechanical gate → adversarial visual review), the stack, the hard
rules (SSR-safe rendering, server-only secrets, backend-only fnf/auth,
Cloudflare bindings via the manifest, shared preview/prod data), the editing
map, and a router to the per-task FUNCTIONAL sub-skills under \`references/\`
(auth, fnf-sdk, fnf-react, quanta-design + app-layouts for \`type: "app"\`,
runtime-and-infra, containers, seo-\*, security-\*). Explains the two kinds:
\`type: "website"\` (standalone, no Higgsfield integration, independent brand)
vs \`type: "app"\` (Higgsfield sign-in + fnf SDK, Quanta + standard layouts).
Everything you need is under this skill — do NOT search the skill library
for other design guidance.
