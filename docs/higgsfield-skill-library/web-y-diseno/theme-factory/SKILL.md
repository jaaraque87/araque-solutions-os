# Theme Factory Skill
Colección curada de temas profesionales de fuente+color para estilizar artifacts (slides, docs, reportings, HTML). Cada tema trae paleta cohesiva con hex codes, pairings de fuentes (headers/body) e identidad visual distinta.

## Usage Instructions (aplicar estilo a un deck/artifact)
1. **Show the theme showcase:** mostrar `theme-showcase.pdf` para que el usuario vea todos los temas visualmente (sin modificar nada).
2. **Ask for their choice:** preguntar qué tema aplicar.
3. **Wait for selection:** confirmación explícita del tema elegido.
4. **Apply the theme:** aplicar colores y fuentes del tema al deck/artifact.

## 10 Temas disponibles (cada uno en `themes/<name>.md`)
- **Ocean Depths** — marítimo profesional y calmo.
- **Sunset Boulevard** — colores cálidos y vibrantes de atardecer.
- **Forest Canopy** — earth tones naturales y grounded.
- **Modern Minimalist** — grayscale limpio y contemporáneo.
- **Golden Hour** — paleta otoñal rica y cálida.
- **Arctic Frost** — winter-inspired frío y crisp.
- **Desert Rose** — dusty tones suaves y sofisticados.
- **Tech Innovation** — estética tech bold y moderna.
- **Botanical Garden** — colores de jardín frescos y orgánicos.
- **Midnight Galaxy** — deep tones dramáticos y cósmicos.

## Application Process
Tras seleccionar tema: leer el archivo `themes/<name>.md` → aplicar colores y fuentes consistentemente en todo el deck → asegurar contraste/legibilidad → mantener la identidad visual en todas las slides.

## Create your Own Theme
Si ninguno sirve, crear un tema custom (paleta cohesiva con hex + font pairings + identidad visual) siguiendo el mismo formato de los archivos de `themes/`.
