# Seedance 2.5 prompt contract

Write in English with client-language dialogue. Stay under 30,000 characters. Use, in order: `[Generation Goal]`, `[Reference Material Roles]`, `[Subjects and Relationships]`, `[Object Continuity Rules]`, `[Camera and Look]`, `[Shot List]`, `[Audio]`, `[Maintain Consistency]`.

Map every reference by position and state what to ignore. A look image controls palette/warmth only; reject its people, products, composition, text, and studio lighting.

Require one protagonist and one product. Every object enters through a visible hand. Establish inventory when it enters; prohibit teleportation, duplication, disappearance, and floating.

Specify phone footage: handheld breathing, micro-drift, autofocus settling, and small exposure shifts for shots 1–5; propped, nearly static phone for 6–7; practical lamps/daylight for warmth.

Each shot needs frame, action, line, and verifiable end state, separated by `Instant hard cut.` Assign one speaker and keep silent mouths closed. Generate phone-mic dialogue, room tone, indistinct background conversation, and action sounds. Prohibit narrator, music, captions, titles, graphics, recording UI, and timestamps. Put duration, ratio, resolution, and format only in API parameters.
