¿Qué es una API Key?
Es una "contraseña" que te da cada plataforma para que el pipeline pueda usar sus servicios. Cada una es diferente. Nunca la compartas con nadie.
GEMINI_API_KEY
Para guiones (gratis hasta cierto límite)
→ aistudio.google.com/app/apikey
FAL_KEY
Para generar imágenes y videos (fal.ai)
→ fal.ai/dashboard/keys
ELEVENLABS_API_KEY
Para cambiar la voz del personaje
→ elevenlabs.io/settings/api-keys
KIE_API_KEY
Música de fondo (Suno) — ya configurada
→ kie.ai/dashboard
SUBMAGIC_API_KEY
Para subtítulos y finishing del video
→ submagic.co (settings)
OPENAI_API_KEY
Opcional — para GPT Image 2 directo
→ platform.openai.com/api-keys

Abre el archivo .env.example en la carpeta del proyecto, renómbralo a .env y rellena tus keys:

# ─── ARAQUE SOLUTIONS — Kenza UGC Pipeline ─── # Rellena TODAS las keys antes de correr el pipeline # IA — REQUERIDAS GEMINI_API_KEY=AIzaSy... ← pega tu key aquí FAL_KEY=0a1b2c3d-... ← pega tu key aquí ELEVENLABS_API_KEY=sk_... ← pega tu key aquí KIE_API_KEY=426c134b1ac3697c... ← ya incluida, verifica # IA — OPCIONALES OPENAI_API_KEY=sk-proj-... ← solo si usas GPT Image directo SUBMAGIC_API_KEY=... ← para subtítulos automáticos # PIPELINE — NO CAMBIAR (defaults correctos) DEFAULT_NUM_SCENES=6 DEFAULT_FORMAT=9:16 DEFAULT_GEMINI_VOICE=Leda

🎬 Kenza UGC Pipeline
12 pasos automáticos de guión a video terminado. Haz clic en cada paso para ver los detalles.
🔵
Leyenda: Verde = sin costo de API Azul = requiere API key Gris = opcional
00
Brand Analyzer — Análisis de Marca
Gemini API $0.00

¿Qué hace? Analiza el nombre, producto y tono de tu marca. Genera el "brief" creativo que usarán todos los demás pasos como base.

Input: Nombre de marca + descripción en brands/kenza.json

Output: outputs/<run_id>/brief.json — el cerebro del video

  • Tiempo: ~15 segundos
  • Costo: Gratis (Gemini Flash)
01
Guión — Script Completo UGC
Gemini API $0.01

¿Qué hace? Genera el guión completo del video con estructura HOOK → HISTORIA → PLOT TWIST → CTA. Incluye el texto que dirá Kenza y las indicaciones visuales por escena.

Estructura del video generado:

  • Escena 1 — HOOK: Los primeros 3 segundos que enganchan
  • Escena 2 — STORY 1: El problema o situación
  • Escena 3 — STORY 2: La solución o proceso
  • Escena 4 — PLOT TWIST: El giro inesperado (firma de Morfeo)
  • Escena 5 — CTA: Llamada a la acción final

Output: outputs/<run_id>/guion.json

02
Personaje — Generación con GPT Image 2
FAL.ai $0.41/imagen

¿Qué hace? Genera la imagen del personaje Kenza usando GPT Image 2 a través de fal.ai. Parte de una imagen de referencia y la adapta al contexto de la escena.

Modelo usado: openai/gpt-image-2/edit

  • Resolución: 1024×1792px (9:16 para vertical)
  • Tiempo: ~30-45 segundos
  • Referencia base: assets/kenza/BANANA_PRO_00006_.png
💡
Si tienes imágenes de referencia de tu influencer, ponlas en assets/kenza/ y el sistema las usará automáticamente.
03
Locación — Fondo / Escenario
FAL.ai $0.41/imagen

¿Qué hace? Genera el fondo o locación para cada escena. El personaje y la locación se generan por separado para tener más control artístico.

Modelo: openai/gpt-image-2/edit

  • Escenas posibles: cocina, oficina, exterior urbano, gym, etc.
  • Se combina con el personaje en el paso 04 (Morpheus)
04
Morpheus — Fotogramas de Escena
FAL.ai $0.50/escena

¿Qué hace? Combina el personaje y la locación para crear los fotogramas finales de cada escena. Morpheus "viste" al personaje con la estética de la marca.

Output: 5 imágenes de alta calidad (una por escena)

  • Tiempo: ~60 segundos por escena
  • Formato: PNG 1024×1792px
05
TTS — Voz de Kenza (Gemini)
Gemini TTS $0.02

¿Qué hace? Convierte el guión en voz usando Gemini TTS. Genera el audio WAV que Kenza "habla" en el video.

API: gemini-3.1-flash-tts-preview

  • Voz default: Leda (joven, natural)
  • Otras opciones: Kore, Aoede, Charon, Fenrir
  • Tags de emoción: [excited], [warm], [energetic]
  • Formato: PCM 16-bit, 24kHz mono
# Cambiar voz en .env: DEFAULT_GEMINI_VOICE=Leda # opciones: Leda, Kore, Aoede, Charon
06
Voice Change — Cambio de Voz (ElevenLabs)
ElevenLabs $0.06

¿Qué hace? Toma el audio generado por Gemini y lo transforma al tono único de Kenza usando ElevenLabs Speech-to-Speech.

Endpoint: eleven_multilingual_sts_v2

  • Tono: Define la identidad vocal de Kenza
  • Idioma: Español (multilingual)
  • Output: MP3 44100Hz 128kbps
07
Kling — Clips de Video (IA)
FAL.ai / Kling $1.20 (paso más caro)

¿Qué hace? Convierte cada imagen estática de escena en un clip de video de 5-10 segundos. Este es el corazón del sistema — anima a Kenza.

Modelo: fal-ai/kling-video/o3/pro/reference-to-video

  • Tiempo: 3-5 minutos por clip
  • Resolución: 1080p (9:16)
  • Movimiento: Controlado por el prompt de cada escena
⏳
Este paso puede tardar 15-25 minutos en total para las 5 escenas. Es normal — la IA genera video de alta calidad.
08
Sync — Lip-Sync (Sync-3) — Opcional
Opcional FAL.ai $0.60

¿Qué hace? Sincroniza los movimientos de labios de Kenza con el audio generado. Hace que parezca que Kenza realmente está hablando.

Modelo: fal-ai/sync-lipsync/v3

  • Cuándo usarlo: Cuando el video muestra el rostro de Kenza hablando directamente
  • Cuándo omitirlo: Videos de acción, producto, sin primer plano de cara
  • Para omitir: python run.py --steps 00-07,09-11
09
Music — Música de Fondo (Suno)
Kie.ai / Suno $0.06

¿Qué hace? Genera música de fondo original y única para el video usando Suno V4.5 Plus a través de Kie.ai. La música se adapta al tono y género del video.

  • Duración: Se ajusta automáticamente al largo del video
  • Estilo: Determinado por el guión (upbeat, chill, energetic, etc.)
  • Output: MP3, se mezcla en el paso 10
10
Assembly — Ensamblado Final (FFmpeg)
Sin costo de API $0.00

¿Qué hace? Une todos los clips, mezcla el audio de voz con la música, aplica transiciones y genera el MP4 final.

  • Herramienta: FFmpeg (instalado localmente)
  • Output: outputs/<run_id>/final.mp4
  • Formato: MP4 H.264, AAC audio, 1080×1920px
  • Tiempo: ~30 segundos
11
Subs — Subtítulos + Finishing (Submagic)
Opcional pero recomendado Submagic API $0.10

¿Qué hace? Agrega subtítulos animados estilo TikTok, ajusta el color-grade final y aplica los últimos retoques de producción.

  • Subtítulos: Automáticos, sincronizados, estilo trending
  • Output: outputs/<run_id>/final_subs.mp4
  • Por qué importa: El 85% del contenido en TikTok se ve sin sonido

🎥 Seedance 2.0 Storyboard
Crea prompts YAML cinematográficos para videos de alta calidad. Aprende las reglas en 10 minutos.
🎬
¿Qué es Seedance?
Un sistema de generación de video IA que toma tu prompt YAML y genera clips cinematográficos. El pipeline de Kenza lo usa internamente para los prompts de Kling, pero también puedes usarlo manualmente para crear contenido premium.

Las 4 capas del prompt

1
Identidad de Escena — title + reference_handling + style + visual_feel ▼ ver

reference_handling es SIEMPRE el segundo campo. Nunca lo pongas al final.

title: "Kenza — Lanzamiento Crema Solar" reference_handling: "DO NOT replicate the reference image composition. DO NOT show Kenza standing frontally facing camera. DO NOT show product held at chest level in standard hero pose." style: "TikTok UGC, handheld feel, natural grain, warm golden hour skin tones" visual_feel: "Authentic, unfiltered, like a real friend sharing her routine. Subsurface skin scattering. Soft bokeh background." duration: "10s"
2
Character Modeling — descripción física antes del storyboard ▼ ver
character_modeling: kenza: base: "Latina woman, 24-28, warm olive skin, dark wavy hair past shoulders" features: "Full lips, strong brows, slightly upturned nose, brown almond eyes" emotional_state: "Excited but natural — the genuine excitement of finding something that works" movement_in_this_scene: "Small gestures, no wide arm movements, contained energy"
3
Cinematic Storyboard — cada segundo del video ▼ ver
📐
Regla de timestamps: NO uses intervalos iguales. 1-2s para impactos. 3-5s para acción sostenida. El ritmo desigual hace videos más dinámicos.
cinematic_storyboard: "0s-2s": camera: "Extreme close-up on Kenza's hands opening product, then tilt up slowly" action: "Fingers curl around product, thumbnail traces the cap, eyes widen slightly" lighting: "Warm afternoon backlight, skin glowing from behind" sfx: "Soft cap pop" "2s-5s": camera: "Medium close-up, 90-degree side profile, shallow depth of field" action: "Kenza applies product to cheekbone, jaw relaxes, brief closed-eye satisfaction" lighting: "Single warm key light from right, golden hour tone" "5s-10s": camera: "Slight pull back to medium shot, steady, minimal movement" action: "Kenza faces partial camera, holds product casually at waist level, speaks to camera" dialogue: "Este fue el único que no me hizo brillar como foco." lighting: "Balanced, warm but neutral — product color accurate"
4
Production Notes — constraints, audio, evitar ▼ ver
production_notes: audio_design: "Soft ambient room tone, no music, voice is the only element" subtext: "Kenza is a real person sharing her genuine opinion — NOT an ad performance" critical_constraint: "DO NOT show Kenza in reference-image pose. DO NOT show product frontally at chest height." avoid: "Jitter, bent limbs, identity drift, chaotic composition, character frozen in reference-image pose"

Las 7 reglas de oro de Seedance

  • reference_handling es SIEMPRE el segundo campo — nunca al final del prompt
  • Nombra las poses específicas a evitar — no sirve decir "solo para referencia"
  • Una sola instrucción de cámara por plano — máximo dos con "then"
  • Velocidad asimétrica — si la acción es rápida, la cámara va lenta, y viceversa
  • Stagger de timestamps — intervalos desiguales para ritmo dinámico
  • Nunca usar "epic", "amazing", "beautiful" — da instrucciones visuales concretas
  • Iluminación en cada plano — aunque sean 4 palabras, cambia todo

Prompt para guión UGC — Estructura completa

Eres un experto en contenido UGC viral para TikTok e Instagram. Genera un guión completo para una influencer llamada Kenza. MARCA: [NOMBRE_MARCA] PRODUCTO: [DESCRIPCIÓN_PRODUCTO] OBJETIVO: [vender / awareness / engagement] DURACIÓN: 30 segundos TONO: [natural/energético/emocional/educativo] ESTRUCTURA OBLIGATORIA: - HOOK (0-3s): Frase o acción que pare el scroll. Sin saludo. - STORY 1 (3-10s): El problema real que tenía antes de este producto - STORY 2 (10-20s): Cómo este producto lo resolvió (específico, no genérico) - PLOT TWIST (20-25s): Detalle inesperado o contradicción que genera curiosidad - CTA (25-30s): Una acción concreta (link en bio, comentar, guardar) REGLAS: - Kenza habla como una amiga real, no como publicidad - Primera persona siempre - Sin palabras épicas o clichés de marketing - Cada escena tiene texto para Kenza Y nota visual OUTPUT: JSON con campos scene_id, kenza_text, visual_note, duration_s

Ejemplo completado — Crema solar

HOOK: "Tres años aplicándome bloqueador solar y brillando como si hubiera cocinado mi cara." STORY 1: "No era el sol. Era el producto. Cada crema que probé me dejaba con esa capa blanca grasosa que a las 2 de la tarde parecía aceite." STORY 2: "Este es el único que desaparece en 30 segundos. Sin residuo. Sin blanco. Solo piel normal." PLOT TWIST: "El ingrediente activo es el mismo que usan las cremas de $200. Esta vale 12." CTA: "El nombre está en mi bio. Antes de que vuelva a agotarse."
