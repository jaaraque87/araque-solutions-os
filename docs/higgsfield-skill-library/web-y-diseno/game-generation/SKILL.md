# Game Generation

Always read this SKILL.md before any game task — creating a playable game from a brief, generating game assets (sprites, backgrounds, tilesets, UI, characters, music/SFX), or both. Routes the request to the right pipeline stage and its reference file: planning (design doc), asset generation, or game assembly. A game deliverable is invalid in every mode (including S) without: design/plan.md, design/assets.csv, an approved STYLE FORMULA, design/thresholds.md, and smoke performance numbers (FPS + draw calls). First action on any game request: post the run contract to the chat (mode + artifact list) BEFORE any code or visual. "Quick / быстро / просто прототип / дай ссылку" selects mode S — it never authorizes skipping. No visual output of any kind (generated OR procedurally drawn in code) may exist before a STYLE FORMULA derived from references/stylization.md exists; waiting for the user's approval of the FORMULA is required only when the style is not already explicit in the brief or reference media.
