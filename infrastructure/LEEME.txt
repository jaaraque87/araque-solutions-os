CÓMO USAR — OPCIÓN 1: Instalación completa (recomendado para pod nuevo)
─────────────────────────────────────────────────────────────────────────────
1. Subir TODA la carpeta al pod:
   En RunPod → pod → "File Browser" → subir carpeta
   O por SCP desde tu PC:
     scp -r LTX23_Scripts/ root@{pod-ip}:/workspace/

2. En la terminal del pod:
   cd /workspace/LTX23_Scripts
   bash run_all.sh

3. Esperar ~3-5 horas (depende de la velocidad del pod y del disco)

4. Abrir en el browser:
   https://{POD_ID}-8888.proxy.runpod.net/proxy/8188/

─────────────────────────────────────────────────────────────────────────────

NOTA IMPORTANTE — TODOENUNO y Q4_0:
─────────────────────────────────────────────────────────────────────────────
  El workflow TODOENUNO pide el modelo "Q4_0.gguf" pero ese modelo NO existe
  públicamente en ningún repo de HuggingFace.

  El script 07_workflows.sh parchea automáticamente el JSON del workflow para
  usar Q4_K_M en su lugar (que sí instalamos en script 05).

  Si ComfyUI muestra error de modelo, edita manualmente el nodo UnetLoaderGGUF
  y selecciona: LTX-2.3-22B-distilled-1.1-Q4_K_M.gguf
