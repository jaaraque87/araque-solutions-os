# Email Sequence Design
Crear secuencias de email (drip campaigns) que nutren, activan y convierten.

## Initial Assessment
Chequear `.agents/product-marketing-context.md`. Entender: **Sequence Type** (welcome/onboarding, lead nurture, re-engagement, post-purchase, event-based, educational, sales) · **Audience Context** (quiénes, qué los disparó, qué saben/creen, relación actual) · **Goals** (conversión primaria, relationship, segmentación, qué define éxito).

## Core Principles
1. **One Email, One Job** — un propósito, un CTA principal. 2. **Value Before Ask** — liderar con utilidad, ganarse el derecho a vender. 3. **Relevance Over Volume** — menos y mejores emails; segmentar. 4. **Clear Path Forward** — cada email los mueve, próximos pasos obvios.

## Strategy
**Length:** Welcome 3-7 · Lead nurture 5-10 · Onboarding 5-10 · Re-engagement 3-5. **Timing:** welcome inmediato, early 1-2 días, nurture 2-4 días, long-term semanal/quincenal. B2B evita fines de semana; enviar en hora local.
**Subject lines:** Clear>Clever, Specific>Vague, benefit/curiosity, 40-60 chars. Patrones: pregunta ("Still struggling with X?"), how-to, número ("3 ways to..."), directo ("[Name], your [thing] is ready"), story tease. **Preview text:** ~90-140 chars, extiende (no repite) el subject.

## Sequence Types (emails clave)
- **Welcome (5-7 emails / 12-14 días):** welcome+valor prometido (inmediato) → quick win (d1-2) → story/why (d3-4) → social proof (d5-6) → objeción (d7-8) → feature (d9-11) → conversión (d12-14).
- **Lead Nurture (6-8 / 2-3 sem):** lead magnet+intro → expandir tema → problem deep-dive → solution framework → case study → diferenciación → objection handler → oferta directa.
- **Re-Engagement (3-4 / 2 sem, trigger 30-60d inactividad):** check-in → value reminder → incentivo → last chance (stay or unsubscribe).
- **Onboarding (5-7 / 14 días, coordinar con in-app):** welcome+first step → getting started → feature → success story → check-in (d7) → advanced tip → upgrade (d14+).

## Copy Guidelines
**Structure:** Hook → Context → Value → CTA → Sign-off. **Formatting:** párrafos cortos (1-3 oraciones), white space, bullets, bold sparingly, mobile-first. **Tone:** conversacional, primera+segunda persona, voz activa, "¿suena humano en voz alta?". **Length:** 50-125 palabras transaccional, 150-300 educacional, 300-500 story-driven. **CTA:** botones para primario, links para secundario, un CTA principal, texto = acción+outcome.

## Output Format
Sequence Overview (Name, Trigger, Goal, Length, Timing, Exit Conditions) + por Email (#, Send timing, Subject, Preview, Body, CTA→destino, Segment/Conditions) + Metrics Plan.
