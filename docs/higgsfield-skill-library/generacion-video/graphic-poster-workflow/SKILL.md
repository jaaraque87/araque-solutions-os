# Graphic Poster (Workflow)

Design ONE graphic still - a motion-design poster, a data infographic, or a presentation/keynote frame - with GPT Image 2 (text large and legible), get sign-off, then animate THAT single frame into an ~8s image-to-video with Gemini Omni Flash: camera locked, typography crisp, native sound. A style reference is described in words and rebuilt fresh, never fed into generation; if the user already has a poster, animate theirs directly.
Triggers: "animated poster", "moving / motion poster", "animate this poster / slide / infographic", "animated infographic / title card", "bring this graphic to life".
NOT for: multi-panel storyboard motion-design reels (classicMD-flow / highMD-flow / typographyMD-flow / infographicMD-flow); narrated explainer / story videos (video-explainer-workflow); product ads (tv-ad); a plain clip with no design still (video-generation).
