# Reels Studio Flow

PRIMARY ENTRY POINT for restyling ONE source video (4s–2min) into a vertical 9:16 reel (or 16:9) using a style preset. Use when the user asks to "restyle", "reels studio", "make a reel/short out of this in <style>", or picks a look for their clip. NOT for cutting existing YouTube footage — that is the personal-clipper-flow skill. After loading this skill: browse presets, start a session from one source video + a preset, poll it, poll each clip job, then stitch the clips into one reel.
