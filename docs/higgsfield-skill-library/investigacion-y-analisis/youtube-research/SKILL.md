# Youtube Research

Research YouTube data — search videos, look up channel info & subscribers, fetch video metadata, and read comments. Use when the user asks about a YouTube channel, creator stats, video performance, or wants to find videos by query. For transcript-to-content reformatting (chapters, summaries, blog posts) use the \`youtube-content\` skill instead. NOT for "what's trending/viral on YouTube Shorts" (no specific topic) — use the \`trends\` tool.
