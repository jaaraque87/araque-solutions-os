# Implied Off-Screen Motion
Transmitir el movimiento de un personaje sin mostrar su cuerpo, usando timing preciso de entrada y salida de elementos por los bordes del frame.

## La técnica
1. **Lock the Frame:** declarar explícitamente que el cuerpo no es visible ("Static locked-off camera. The body remains entirely outside the frame").
2. **Choreograph the Exit:** describir el primer elemento saliendo del frame ("right hand gradually sweeps upward and out of the top-right edge").
3. **Choreograph the Entrance:** describir el segundo elemento entrando como continuación del mismo movimiento ("as the right hand exits above, the left hand enters from the bottom-right").
4. **Sync the Pace:** ambos elementos comparten el MISMO speed anchor para vender la ilusión de un cuerpo conectado ("both arms move at exactly the same ultra-slow pace — one full implied rotation across the clip").

## Ejemplo: Unseen Whirling Dervish
Close-up locked frame que captura solo las manos y antebrazos de un derviche girando; el cuerpo nunca entra al frame, pero el timing de manos entrando/saliendo implica la rotación completa.
