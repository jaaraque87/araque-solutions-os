# Content Analyzer

General-purpose content analysis. A broad, growing collection of analysis
modes — each parses a concrete content artifact the user already has into
structured, enhancer-backed analysis for a downstream use case. Pick the mode
matching your intent and load its reference via skill\_view.
Use for: "analyze this for editing", "analyze this for marketing", any
"analyze X for <use case>" where X is a concrete artifact already supplied.
NOT for: trend / viral / creator discovery research (use research/trend-picker),
product input preprocessing (use analyzer/product-analyzer),
brand asset extraction (use analyzer/brand-analyzer),
generation itself (use media/\* or workflow-generation/\*).
