# Youtube Content

Fetch YouTube video transcripts and transform them into TEXT content only (chapters, summaries, threads, blog posts). Use when the user asks to summarize a video, requests a transcript, or wants to reformat a video's spoken content into written form. DO NOT use when the user wants to clip, cut, or create short video clips (TikTok/Reels/Shorts/viral moments) — for those, use the \`youtube\_clipping\` tool, which produces actual rendered short videos with burned-in subtitles.
